模板图目录（默认对应塔塔冒险队）
=================================

把游戏截图裁剪出来的 PNG 放在这里，文件名就是任务代码里引用的名字。

命名建议
- btn_xxx.png      可点击按钮（如 btn_mail）
- home_marker.png  主界面的稳定特征，用来确认"我在哪"
- popup_xxx.png    弹窗标题/特征

截图要求
1. 用 `python main.py capture` 截的图（与运行时同一分辨率），不要用手机截图或缩放过的图。
2. 只截稳定元素：按钮图标 + 文字，避开动画、倒计时、半透明蒙层、会变化的数字。
3. 尺寸不要太小（建议 >= 20x20 像素），且该元素在画面中尽量唯一。
4. 一个模板只对应一个元素；需要匹配列表里的多个相同项时用 find_all。

为什么必须同分辨率
当前实现是单尺度模板匹配（速度最快）。换分辨率后模板尺寸对不上，匹配分数会明显下降。
如果要支持多分辨率，可在 core/vision.py 的 find/find_all 里加多尺度循环。
